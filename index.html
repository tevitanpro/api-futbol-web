💡 ¿Cómo configurar el Motor JackBusca?

1. Tarjetas: el promedio del árbitro es opcional. Si no lo tienes, el motor puede intentar inferirlo de líneas O/U disponibles.

2. Córners: no necesitas buscar el promedio de cada equipo; si existen líneas O/U de Pinnacle, el motor estima una distribución a partir de ellas.

3. Datos faltantes: déjalos vacíos. JackBusca nunca inventa cuotas ni promedios y mostrará DATOS INSUFICIENTES cuando no haya base matemática suficiente.

4. Casa donde apuestas: también es opcional; solo se usa para calcular Edge/EV y detectar valor.
